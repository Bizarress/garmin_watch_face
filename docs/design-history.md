# デザイン選定の経緯

2026-10-13〜14 に、HTML/SVG のモックを出して選ぶ形でデザインを絞り込みました。
ここには、決まった方針と、なぜそうなったかを残します。

## 目指すもの

- 依頼は「おしゃれな、有料級のデザイン」
- 本人いわく、本当の好みは「シンプルおしゃれ」。ただし、要素を減らしただけのミニマルは「ありきたり」として通らない
- 残った候補に「データを別の世界観に読み替える」ものが多いのは、良かった案がたまたまそうだっただけで、好みそのものではない
- 参考に挙がったもの：Connect IQ ストアの「Nova Coffee Customizable」（琥珀色のドット調の画面）、Apple Watch のフェイス

## 進め方の教訓

- 洗練では、その案の「らしさ」（細かい文字の密度、レシート感、表紙らしさ）を残す。文字サイズの一律ルールで個性を消さない
- 新しい案を求められたら、既存の候補を組み合わせず、まだ出していない方向から考える
- モックは実機の `Dc` で描ける表現に限り、画像に書き出して崩れがないか確かめてから見せる
