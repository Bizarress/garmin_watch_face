# N°04 本日のお会計

- 状態：仕様たたき台（未実装）
- モック：[mock/index.html](mock/index.html)（採用案＝第 5 弾の元の案、通常表示と常時表示）
- アプリ：`app/`（表示名 Receipt）

## コンセプト

1 日をレシートとして印字する。今日の歩数や心拍が「品目」、時刻が「合計」。時計の上端から感熱紙が出てくるように見せる。

## 画面構成（390×390）

細かい等幅の文字が並ぶ密度が、この案のレシートらしさを作っている。洗練で文字を大きくした版は「レシート感が薄い」として採用しなかったので、文字は小さいまま残す。

| 要素 | 位置・大きさ | 色 |
|---|---|---|
| 地 | 全面 | 黒 `#000000` |
| 紙 | x 88〜302、上端から y=338 まで。下端は 11px 間隔のギザギザ（谷 338、山 348） | 生成り `#F5F2EA` |
| 店名 `LIFE MART` | 中央、y=52、等幅 17px 太字、字間 3 | 墨 `#23211E`（紙の上の文字はすべて同じ） |
| 日付行 `2026/10/13 TUE  NO.286` | 中央、y=70、11px。NO. はその年の何日目か | 墨 |
| 区切り | y=86 と y=198、`- - - -` 11px | 墨 |
| 品目 5 行 | 左 x=96、右寄せ x=294、y=106 から 19px 間隔、13px | 墨 |
| `TOTAL` | x=96、y=238、14px 太字 | 墨 |
| 時刻 | 右寄せ x=294、y=246、50px 太字、字間 -1 | 墨 |
| バーコード | y 260 前後〜300 前後、太さの違う縦棒。時刻から作る | 墨 |
| `THANK YOU FOR TODAY` | 中央、y=320、10px、字間 2 | 墨 |

品目（上から）：STEPS、HEART RATE、BODY BATTERY、CALORIES、BATTERY。

## 表示するデータ

| 品目 | 取得元（予定） | 取れないとき |
|---|---|---|
| STEPS | `ActivityMonitor.getInfo().steps` | `0` |
| HEART RATE | `Activity.getActivityInfo().currentHeartRate` ほか | `--` |
| BODY BATTERY | `SensorHistory.getBodyBatteryHistory`（要確認） | `--` |
| CALORIES | `ActivityMonitor.getInfo().calories` | `--` |
| BATTERY | `System.getSystemStats().battery` | ― |
| NO. | その年の何日目か（計算） | ― |

## 状態による変化

- 歩数が目標に届いたら、紙の上に赤い「済」の判を斜めに押す（元の案の仕掛け。判の絵柄は未作成）

## 常時表示

モックのとおり。黒地に、紙の輪郭だけを暗い線（`#4A4840`、2px）で描き、時刻を灰色（`#7A7A7A`、等幅 56px）で中央に出す。1 分ごとに位置を数 px ずらす。
