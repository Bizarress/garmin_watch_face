# N°08 太陽の弧

- 状態：仕様たたき台（未実装）
- モック：[mock/index.html](mock/index.html)（採用案の明け方・昼・夕方・夜と、元の案）
- アプリ：`app/`（表示名 Sun Arc）

## コンセプト

画面に地平線を引き、今日の太陽が通る道を点線の弧で描く。点がいまの太陽の位置。夜は同じ弧を月が渡る。空の色が時間帯で移り変わる。

## 画面構成（390×390）

| 要素 | 位置・大きさ |
|---|---|
| 地平線 | y=232、横いっぱい、1.5px |
| 弧（太陽の通り道） | 左端 x=58（日の出）〜右端 x=332（日の入り）、高さ 144px の放物線。2px の点線（2 描いて 7 空ける） |
| 太陽 | 弧の上、位置 = (今 − 日の出) ÷ (日の入り − 日の出)。半径 10 の丸と、半径 22・34・46・58 の薄い光の輪（不透明度 7%） |
| 地面 | 地平線より下を暗い色で塗る |
| 日の出・日の入りの時刻 | 弧の両端の下、y=260、20px。明け方は日の出を、夕方は日の入りを白い太字にする |
| 時刻 | 中央、y=320、62px、細め |

## 時間帯ごとの描き分け

| 時間帯 | 空 | 足すもの | 地面 |
|---|---|---|---|
| 明け方 | 暗い藍 `#1E2448`。地平線の上 100px に藍→紫 `#5A3F66`→桃 `#C98494` の帯 | 桃色に照らされた薄雲（横長の角丸、不透明度 55%）、山の影 `#151935`、まばらな星、昇る太陽 `#FFC9A0` | `#11152C` |
| 昼 | 上 `#123E70` → 中 `#2F6AA4` → 地平線 `#6F9FC8` | 光の輪つきの太陽 `#FFF6D6`、白い薄雲、遠い山 `#5D86A8`、近い山 `#2E4F45` | `#18291F` |
| 夕方 | 暗い紫 `#2A1E3C`。地平線の上 100px に紫→臙脂 `#6B2E40`→橙 `#D9643A` の帯 | 橙に縁取られた薄雲、山の影 `#1C1224`、半分沈む太陽 `#FFA24C`、一番星 | `#140C1A` |
| 夜 | 上 `#03050D` → 地平線 `#13234A` | 60 個ほどの星（大きさと明るさに差）、月（満ち欠けつき） | `#05070C` |

- 色は 4 段で切り替えず、日の出・日の入りの時刻を基準に少しずつ移す
- グラデーションは、実機では細い横帯（2〜4px）を重ねて描く
- 山の稜線と星の配置は、乱数の種を固定して毎回同じ形にする

## 表示するデータ

| 表示 | 取得元（予定） | 取れないとき |
|---|---|---|
| 日の出・日の入り | `Weather.getSunrise()` / `getSunset()`。場所は天気の観測地点など | 最後に取れた値。初回は 6:00／18:00 で仮置き |
| 月の位置・満ち欠け | 日付と場所から計算 | 満ち欠けだけ描き、位置は象徴にする |
| 時刻 | `System.getClockTime()` | ― |

## 常時表示

地を黒にし、地平線・弧の点線・太陽（または月）を暗い色で描き、時刻を暗い白で出す。空と地面の色、薄雲、山、星は描かない。1 分ごとに位置を数 px ずらす。

## 経緯

第 9 弾で候補に残した。背景色を時間帯で変える方向で、昼が「のっぺり」とされたため、空のグラデーション・光の輪・薄雲・山を足した（昼 ①、「他のデザインと平仄を合わせるなら①」）。明け方・夕方は、暗い空に地平線の光の帯を入れる形に戻した。
