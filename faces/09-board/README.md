# N°09 掲示板

- 状態：仕様たたき台（未実装）
- モック：[mock/index.html](mock/index.html)（採用案＝第 9 弾の元の案）
- アプリ：`app/`（表示名 Board）

## コンセプト

電子ペーパーの情報端末のような、灰白の紙に黒インクだけの画面。罫線で区切った紙面に、時刻・天気・歩数を載せる。濃淡はグラデーションではなく網点（ディザ）で出す。

## 画面構成（390×390）

小さな文字の密度もこの案の一部なので、文字は小さいまま残す（ただし読めること）。

| 要素 | 位置・大きさ | 色 |
|---|---|---|
| 地 | 全面 | 紙 `#E3E0D8` |
| 曜日と日付 `WEDNESDAY 14 OCT` | 中央、y=74、12px 太字、字間 4 | 墨 `#161616` |
| 時刻 | 中央、y=160、92px 極太、字間 -2 | 墨 |
| 太い罫線 | y=186、x 22〜368、3px | 墨 |
| 縦の罫線 | x=194、y 202〜282 | 墨 |
| 左の枠：天気 | 線画の天気アイコン（太陽と雲など）、気温 `18°` 30px 太字、その下に `H 21  L 12  20%` 10px | 墨、補足は `#55524B` |
| 右の枠：歩数 | `8,421` 30px 太字、網点の進捗バー（枠 116×10）、その下に `STEPS  84%` 10px | 墨、補足は `#55524B` |
| 細い罫線 | y=298、x 48〜342 | 墨 |
| 下の行 `BB 84   HR 62   87%` | 中央、y=326、12px 太字、等幅 | 墨 |

## 表示するデータ

| 表示 | 取得元（予定） | 取れないとき |
|---|---|---|
| 天気・気温・最高・最低・降水確率 | `Weather.getCurrentConditions()` | アイコンなし、`--°` |
| 歩数・達成率 | `ActivityMonitor.getInfo().steps` / `.stepGoal` | `0` |
| BB（Body Battery） | `SensorHistory.getBodyBatteryHistory`（要確認） | `--` |
| HR（心拍） | `Activity.getActivityInfo().currentHeartRate` ほか | `--` |
| 電池 | `System.getSystemStats().battery` | ― |

天気のアイコンは、切り絵（N°13）と同じ 8 つのまとめ方（晴れ、晴れ時々くもり、くもり、雨、雷、雪、霧・もや、風・嵐）に合わせて線画で用意する。

## 常時表示

明るい地は常時表示に使えないため、白黒を反転する。黒地に、時刻と罫線だけを暗い灰色で描く。1 分ごとに位置を数 px ずらす。
