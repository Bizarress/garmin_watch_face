# N°10 暦

- 状態：仕様たたき台（未実装）

- アプリ：`app/`（表示名 Calendar）

## コンセプト

黒と赤の 2 色インクで刷った、壁掛けカレンダーのような画面。今月のカレンダーが主役で、今日だけ赤い丸。

## 画面構成（390×390、採用案 10-B）

| 要素 | 位置・大きさ | 色 |
|---|---|---|
| 地 | 全面 | 紙 `#E6E3DB` |
| 時刻 | 中央、y=92、54px 太字 | 墨 `#161616` |
| 月名 `OCTOBER` | 中央、y=120、20px 太字、字間 6 | 赤 `#C4302B` |
| 曜日の見出し `S M T W T F S` | y=156、列の間隔 40px（中央の列が x=195）、18px 太字 | 日曜は赤、ほかは墨 |
| 見出しの下線 | y=164、2px | 墨 |
| 日付 | 1 行目のベースライン y=190、行の間隔 30px、22px | 日曜は赤、過ぎた日は灰 `#9A968D`、これからの日は墨 |
| 今日 | 半径 15 の赤い丸に、紙の色で太字の日付 | 赤と紙 |

## 表示するデータ

時刻・日付・今月の日の並び（`System.getClockTime()`、`Time.Gregorian`）だけ。

## 常時表示

案：黒地に、時刻と今日の日付（赤い輪郭の丸）だけを暗く出す。カレンダー全体は描かない。1 分ごとに位置を数 px ずらす。
