# N°11 表紙

- 状態：仕様たたき台（未実装）

## コンセプト

毎日届く雑誌の表紙。月名が題字、巨大な時の数字が表紙の写真、歩数や心拍が表紙の見出し。細い縦線のディドーネ体（Bodoni 系）で組む。

## 画面構成（390×390）

見出しの小さな文字と、題字・数字の大きさの差が「表紙っぽさ」を作っている。洗練で見出しを大きくした版は「表紙っぽさがなくなった」として採用しなかったので、この比率を守る。

| 要素 | 位置・大きさ | 色 |
|---|---|---|
| 地 | 全面 | 紙 `#EDE8DE` |
| 題字（月名）`OCTOBER` | 中央、y=96、ディドーネ体 54px、字間 1 | 墨 `#141414` |
| 時（表紙の写真） | x=150 を中心、y=300、ディドーネ体 220px、字間 -8 | 墨 |
| 分 `08` | x=300 を中心、y=150、32px やや太字。下に幅 32px・2px の線（y=158） | 赤 `#D2362B` |
| 見出し 3 つ | x=300 を中心、数字は斜体のディドーネ体 20px（y=200・240・280）、その 12px 下にラベル 7.5px 太字・字間 2 | 墨 |
| 下の行 `WED 14 · VOL. 287` | 中央、y=338、9px、字間 4。VOL. はその年の何日目か | 灰 `#6A665E` |

見出し（上から）：`8,421` STEPS、`62` BPM、`84` BODY BATT.

## 表示するデータ

| 表示 | 取得元（予定） | 取れないとき |
|---|---|---|
| 題字の月名 | `Time.Gregorian` | ― |
| STEPS | `ActivityMonitor.getInfo().steps` | `0` |
| BPM | `Activity.getActivityInfo().currentHeartRate` ほか | `--` |
| BODY BATT. | `SensorHistory.getBodyBatteryHistory`（要確認） | `--` |
| VOL. | その年の何日目か | ― |

## 常時表示

明るい地は使えないため、黒地に白黒を反転した版にする。題字と時の数字を暗い灰色で描き、見出しは省く。分は暗い赤。1 分ごとに位置を数 px ずらす。
