# N°13 切り絵

- 状態：仕様たたき台（未実装）
- モック：[mock/index.html](mock/index.html)（時間帯 4 × 天気 4、追加の天気 4、元の案）
- アプリ：`app/`（表示名 Paper Cut）

## コンセプト

色紙を重ねて切り抜いた絵本のような画面。空・太陽や月・3 つの丘・数字が、それぞれ紙の層として影を落とす。時間帯と天気で絵が差し替わる。

## 画面構成（390×390）

| 層（奥から） | 形 |
|---|---|
| 空 | 全面 |
| 星（夜・晴れのみ） | 小さな丸 5 つ |
| 太陽／月 | 丸（月は丸から空の色の丸をずらして抜いた三日月） |
| 雲・雨・雪・霧・風 | 天気ごとの紙片（下表） |
| 遠い丘 | 中心 (120, 560)、半径 290 の円 |
| 中の丘 | 中心 (330, 540)、半径 250 の円 |
| 近い丘 | 中心 (40, 520)、半径 210 の円 |
| 日付 `WED 14` | 中央 x=190、y=120、20px 太字、字間 4 |
| 時刻 | 中央 x=190、y=232、100px 極太、字間 -2 |

どの層も、右下（x+4, y+6）に黒・不透明度 30% の影を落とす（朝は 18%、夕は 22%）。

## 天気（載せるものを決める）

時計から取れる天気（`Weather.CONDITION_*`、54 種類）を 8 つにまとめる。

| まとめ方 | 主な種類 | 絵 |
|---|---|---|
| 晴れ | CLEAR、FAIR、MOSTLY_CLEAR、PARTLY_CLEAR | そのまま |
| 晴れ時々くもり | PARTLY_CLOUDY、THIN_CLOUDS | 太陽に雲が 1 つかかる |
| くもり | CLOUDY、MOSTLY_CLOUDY | 空と丘を灰色へ 35% 寄せ、雲を 2 つ |
| 雨 | RAIN、LIGHT_RAIN、HEAVY_RAIN、DRIZZLE、SHOWERS ほか | 55% 寄せ、暗い雲と雨粒（短い紙片） |
| 雷 | THUNDERSTORMS ほか | 60% 寄せ、黒い雲と黄色い紙の稲妻 |
| 雪 | SNOW、FLURRIES、SLEET、HAIL、ICE、WINTRY_MIX ほか | 45% 寄せ、雲と雪の粒、丘の上に白い縁 |
| 霧・もや | FOG、MIST、HAZE、SMOKE、DUST、SAND ほか | 35% 寄せ、丘の前に横長の白い紙の帯 |
| 風・嵐 | WINDY、SQUALL、TORNADO、HURRICANE ほか | うねる白い紙の帯 |

「不明」や天気が取れないときは晴れの絵で代用する。時間帯 4 × 天気 8 ＝ 32 通り。

## 表示するデータ

| 表示 | 取得元（予定） |
|---|---|
| 時刻・日付 | `System.getClockTime()`、`Time.Gregorian` |
| 天気 | `Weather.getCurrentConditions().condition` |
| 時間帯の境目 | `Weather.getSunrise()` / `getSunset()`（取れないときは 6:00／18:00） |

## 常時表示

案：黒地に、丘の稜線と太陽／月の輪郭だけを暗い線で描き、時刻を暗いクリームで出す。1 分ごとに位置を数 px ずらす。
