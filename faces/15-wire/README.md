# N°15 針金

- 状態：仕様たたき台（未実装）
- モック：[mock/index.html](mock/index.html)（採用案 15-B と元の案）
- アプリ：`app/`（表示名 Wire）

## コンセプト

画面の端から端まで通した 2 本の針金を曲げて、時と分の数字を作る。上の黒い針金が時、下の赤い針金が分。毎分、曲げ直される。

## 画面構成（390×390、採用案 15-B）

| 要素 | 位置・大きさ | 色 |
|---|---|---|
| 地 | 全面 | 生成り `#EEE8DD` |
| 日付 `WED 14` | 中央、y=58、20px、字間 5 | 灰 `#5E5A52` |
| 時の針金 | 数字の下端（ベースライン）y=184、数字の高さ 105px（倍率 1.05）、中央寄せ | 黒 `#1A1A1A` |
| 分の針金 | ベースライン y=312、同じ大きさ | 赤 `#C2362B` |
| 針金の太さ | 3.5px、端とつなぎ目は丸 | ― |
| 影 | 同じ線を (+3, +6) ずらして、黒・不透明度 10% | ― |

針金は左端の外（x=-20）から入り、数字の手前で少し下がってベースラインに乗り、数字を描いて、右端の外（x=410）へ抜ける。

## 数字の作り方

- 数字ごとに、高さ 100 の箱の中の通過点を決める。入口は左下 (0,100)、出口は右下（幅,100）。隣の数字とはベースラインでつながる
- 通過点をなめらかな曲線（Catmull-Rom）でつなぎ、前もって細かい点の列にしておく。実機では短い線をつないで描く
- モックで作ったのは 0（幅 58）、1（幅 36）、8（幅 60）とコロン（幅 24）。残りの 2〜7、9 はこれから作る

## 実装の見通し

- `Dc.setAntiAlias(true)`（API 3.2.0〜）と `setPenWidth()` で、なめらかな太い線が描ける（SDK で確認済み）
- 描くのは毎分 1 回、2 本だけなので処理は軽い
- 太い線のつなぎ目の見え方は、シミュレーターで確かめる。気になるなら、つなぎ目に小さな丸を置く

## 表示するデータ

時刻と日付だけ（`System.getClockTime()`、`Time.Gregorian`）。

## 常時表示

細い線だけで点灯画素が少ないので、相性が良い。黒地に、時の針金を暗い灰、分の針金を暗い赤で描く（影なし）。1 分ごとに位置を数 px ずらす。
